# Web MVP Retrospective

## What Changed

- Added the Vite, React, TypeScript, and React Three Fiber project foundation.
- Implemented a full-screen 3D dodge game scene with a player, arena floor, lighting, falling obstacles, score, dodge count, high score, game over, and restart.
- Added desktop keyboard controls and mobile-oriented pointer drag controls.
- Moved obstacle rendering to an instanced mesh to reduce React work during the frame loop.
- Added pure game-logic tests for movement, collision, difficulty scaling, score calculation, and high-score selection.
- Documented the MVP design in `docs/superpowers/specs/2026-06-11-web-mvp-design.md`.

## What Went Well

- The game loop reached a playable state quickly.
- Pure logic tests made the collision and scoring rules easier to verify.
- Instanced obstacle rendering aligned the implementation with the web optimization goal.
- Production preview rendered correctly in Chrome.

## What Was Tricky

- The first sandboxed `npm install` and local preview commands were blocked by network and port permissions, so approved execution was required.
- Latest ESLint/Vitest versions produced Node 23 engine warnings. ESLint and Vitest were pinned to compatible major versions, though one transitive `typescript-eslint` engine warning remains during install.
- Browser plugin tooling was not available in this session, so visual verification used Chrome through Computer Use.

## Verification Performed

- `npm run lint`
- `npm run test`
- `npm run build`
- `npm run preview`
- HTTP checks for preview HTML, JavaScript, and CSS assets
- Chrome visual check for nonblank 3D rendering
- Chrome gameplay check for start flow, live score updates, visible falling obstacles, and keyboard input response

## Follow-Up Work

- Test touch controls on a real mobile browser.
- Decide whether to tune the bundle warning with code splitting or keep it as acceptable for a Three.js MVP.
- Add stronger game-over/restart automated or manual checks once a browser automation tool is available.
- Consider a polish pass for obstacle shape, hit feedback, and difficulty feel.
